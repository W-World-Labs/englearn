# EngLearn public source

This repository owns the complete TanStack Start/Vite language-learning application:
adaptive assessments, vocabulary, grammar, open-book reader, exams, daily learning,
local records and W-ID account synchronization. Preserve existing algorithms,
content IDs, API/OpenAPI contracts, ownership checks and functional assertions.
Read README.md, NOTICE.md and PUBLIC_SOURCE.md before changing scope or assets.

Use the simplest direct change and existing functions/types. Use modern-web-guidance
before frontend work. Do not add unnecessary tests or weaken the existing checks.
Keep all upstream notices and original authorship. MIT covers original application
code only; original learning content and imported resources have separate terms.

Do not publish private history, credentials, registry tokens, runtime state, user
records, device inventories, deployment bindings, paid/protected plugins or material
without explicit redistribution rights. Free access and an author's code license do
not license every textbook, examination question, recording or model output.

GitHub CI uses only a PUBLIC repository and standard hosted runners. Installation,
existing product checks, builds and packaging run there; local work is source editing
and static metadata/provenance inspection. Do not contact production, start a local
product, download models or generate replacement audio as part of source review.

Public configuration uses an operator's own issuer, provider and optional telemetry.
Guest mode, browser backup, record ownership and conflict handling remain supported.
Do not replace integrations with stubs or copy a consumer's private implementation.
Deployment scripts are explicit operator-run examples and never public CI steps.
